Ko sam ja?

Zdravo! Ja sam Stefan Staničić, učenik četvrte godine koji se bavi programiranjem. Razvijam projekte u C# i C++-u, od osnovnih algoritama do Windows Forms aplikacija.

Zadaci na ovoj stranici rade u Visual Studiju 2019: rad sa slikama i listama, ListView i ListBox, Word editor sa RichTextBox-om, kviz sa više formi i evidencija učenika.

Za baze koristim MySQL (XAMPP i phpMyAdmin): tabele, SQL upiti i povezivanje sa C# aplikacijom preko MySql.Data.

Alati i tehnologije

  • C#
  • .NET Framework 4.7.2
  • Windows Forms
  • Visual Studio 2019
  • MySQL
  • SQL upiti
  • XAMPP
  • phpMyAdmin
  • NuGet
  • ListView · RichTextBox
